事例ページを追加します。会社名は $0、URLは /works/$1/ です。

## 始める前に私に確認すること（分からないまま作らない）
- 会社名・ロゴ・写真の掲載許諾があるか
- 用途（開業・移転・周年・受付など）、色、サイズ、仕上げ方
- デザインで工夫した点
- 飾った場所と、その後にいただいた声（いただいた言葉はそのまま使う。言い換えや創作はしない）
- 写真ファイルの場所

## 作り方
1. title は「{社名}さまの会社猫｜{デザインの特徴}の{色}の招き猫」の型で、30字前後にする
2. description は80〜110字。背景・デザイン・その後を1文ずつ書く
3. 本文は「背景 → デザインの考え方 → お届けと仕上げ → 飾った後の声 → 写真」の順にする
4. og:type は article。Article と BreadcrumbList の構造化データを入れる。評価やレビューのマークアップは入れない
5. /works/ の一覧とトップの事例欄に追加し、sitemap.xml にも追加する
6. 写真は WebP にして、全てに内容を表す alt を付ける
7. 最後に .claude/skills/seo-check/SKILL.md の基準で点検し、変更ファイルと新しく書いた文を報告する
